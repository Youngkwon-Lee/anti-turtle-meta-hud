# Anti Turtle Meta HUD v0.1.0

The first public research-prototype release connects a Meta Display glasses orientation sensor to a lightweight posture-coaching HUD, a desktop camera receiver, and native macOS feedback.

- Repository: <https://github.com/Youngkwon-Lee/anti-turtle-meta-hud>
- Live demo: <https://stage-codex-bridge-head-only.vercel.app/?demo=1&source=head>
- License: Apache-2.0

## Included

- personal neutral-baseline calibration from glasses orientation;
- HEAD-only relay and optional HEAD + NU torso HYBRID mode;
- fresh/stale-aware browser camera receiver;
- native macOS Notification Center and live menu-bar feedback;
- Meta AI Web App installation instructions and QR code;
- Node, Python, and Swift CI, contribution templates, roadmap, clinical limits, and open-source review.

## Verification evidence

- 53 Node tests and 7 Python tests pass;
- JavaScript syntax checks, Swift typecheck, workflow lint, and whitespace checks pass;
- GitHub Actions verifies Node/Python on Ubuntu and Swift on macOS;
- the public demo returns HTTP 200 and an unused session returns an empty shared-Redis telemetry response;
- pre-release physical Meta Display testing covered motion permission, calibration, live HEAD angle changes, desktop HUD reception, and native macOS feedback;
- the v0.1 release commits after physical testing change only documentation and CI configuration, not application runtime behavior.

HYBRID operation remains implemented and tested with synthetic/unit coverage, but was not physically re-verified for this release because the NU torso sensor was unavailable.

## Important limitations

The displayed value is personal-baseline head pitch, not clinical craniovertebral angle (CVA) and not a forward-head-posture diagnosis. The desktop camera is a local video background in v0.1; it does not perform clinical landmark analysis. Standard Ray-Ban Meta camera glasses do not expose their outward-facing camera to ordinary web pages.

The public relay is an unauthenticated demonstration service. Do not use identifying session labels, patient data, or production health information. Review `SECURITY.md` and `docs/CLINICAL_LIMITS.md` before deployment or research use.
