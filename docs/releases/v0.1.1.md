# Anti Turtle Meta HUD v0.1.1

This maintenance release makes personal head-orientation calibration more reliable without changing the project's wellness/research scope.

- Repository: <https://github.com/anti-turtle-lab/anti-turtle-meta-hud>
- Stable live demo: <https://stage-codex-bridge-head-only.vercel.app/>
- License: Apache-2.0

## Included

- warm-up followed by a continuous stable three-second hold;
- median baseline selection after the hold succeeds;
- movement rejection with visible restart feedback;
- `--°` output until a trustworthy baseline exists;
- stale, sensor-gap, and large-jump recovery that requires recalibration;
- bidirectional anatomical feedback mapped to the Meta Display beta convention for forward flexion and backward extension;
- a dedicated McKenzie-style cervical extension endpoint instead of rotating the neutral anatomy image;
- signed head-deviation relay data so the glasses and Mac receiver animate the same direction;
- replay tests covering calibration and continuity behavior;
- Git-triggered Vercel deployment disabled in favor of reviewed prebuilt artifacts.

## Important limitations

The displayed value is a personal-baseline head-pitch deviation. It is not craniovertebral angle (CVA), forward-head translation, a forward-head-posture diagnosis, or a substitute for professional assessment. The browser camera is a local visual background and does not perform clinical landmark analysis.

The public relay is an unauthenticated demonstration service. Never use identifying session labels, patient data, or production health information. Review `SECURITY.md` and `docs/CLINICAL_LIMITS.md` before reuse.
